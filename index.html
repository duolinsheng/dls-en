Tutor model

          

            
            
            
            
          

          
          
            Run node server.js first and use /api. To talk to Ollama directly, use
            http://127.0.0.1:11434. For DeepSeek, use https://api.deepseek.com/v1 and upload a
            JSON config file that contains your API key. Settings are stored only in this browser.
          
          

            
Download a model

            
Run this command in a terminal:

            

              ollama pull qwen3.5:0.8b
              
            

            
Other handy commands:

            

              
ollama listSee installed models

              
ollama rm MODELRemove a model

              
ollama serveStart the Ollama service

            

            
Memory guide: 0.5b ≈ 512 MB | 1.5b ≈ 1.5 GB | 3b ≈ 2.5 GB | 7b ≈ 5 GB

            Try “How do I say hello in Cantonese?” The tutor looks words up in the dictionary when it needs to and
            suggests what to learn next.
